# Kho tri thức mẫu

Đặt các tài liệu đã được phê duyệt trực tiếp vào thư mục `knowledge/`, ví dụ:

- `01-thong-tin-lien-he.md`
- `02-thu-tuc-cu-tru.docx`
- `03-huong-dan-vneid.pdf`
- `04-canh-bao-lua-dao.md`

File `README.md` này được chương trình tự động bỏ qua khi nạp dữ liệu.

Mỗi tài liệu nên ghi rõ:
- tên văn bản hoặc nguồn;
- ngày ban hành/cập nhật;
- đơn vị/cán bộ kiểm duyệt;
- phạm vi áp dụng;
- ngày hết hiệu lực nếu có.

Không đưa dữ liệu dân cư, hồ sơ nghiệp vụ, tài liệu điều tra, bí mật nhà nước hoặc dữ liệu cá nhân nhạy cảm vào kho Gemini.
