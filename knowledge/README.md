# Kho tri thức mẫu

Đặt các tài liệu đã được phê duyệt vào thư mục `knowledge/`, ví dụ:

- `01-thong-tin-lien-he.md`
- `02-thu-tuc-cu-tru.docx`
- `03-huong-dan-vneid.pdf`
- `04-canh-bao-lua-dao.md`

Mỗi tài liệu nên ghi rõ:
- tên văn bản hoặc nguồn;
- ngày ban hành/cập nhật;
- đơn vị/cán bộ kiểm duyệt;
- phạm vi áp dụng;
- ngày hết hiệu lực nếu có.
